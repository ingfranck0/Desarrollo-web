PROYECTO - ACTIVIDAD 65
Desarrollo de Sistemas Web I
Pop-Up y Envío de Datos

ARCHIVOS:
- index.php       Captura los datos.
- resultados.php  Recibe y muestra los datos mediante PHP.
- app.js          Controla la ventana emergente.
- style.css       Da formato visual a las interfaces.

INSTALACIÓN CON XAMPP:
1. Copiar la carpeta Proyecto dentro de:
   C:\xampp\htdocs\

2. Abrir XAMPP y activar Apache.

3. Abrir en el navegador:
   http://localhost/Proyecto/

4. Escribir nombre, edad, ciudad y pasatiempo favorito.

5. Presionar "Ingresar datos".

6. Verificar que resultados.php muestre los datos.

7. Presionar "Registrar otro dato" para visualizar el Pop-Up.

8. En la ventana emergente seleccionar "Sí, regresar" para volver a index.php.

GITHUB:
Antes de entregar, sustituir el enlace de GitHub del documento de la actividad
por el enlace real del repositorio donde se suban estos archivos.
